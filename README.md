# Cloud Cost Simulation Pay As You Go

This Python script simulates and compares IT infrastructure costs between a traditional on-premise setup and a cloud computing (pay-as-you-go) model. It demonstrates how cloud computing can reduce costs by aligning expenses directly with actual resource usage, contrasting with the fixed, often over-provisioned costs of on-premise infrastructure. The simulation shows cost fluctuations over several months based on varying usage levels.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt.
3. Run the script using: `python main.py`
